# 数据集计划与讨论

本目录是本项目数据集选型、许可核查、处理流程、数据计划与相关讨论结论的**唯一正式更新位置**。后续讨论形成新的数据集结论或行动计划时，直接更新这里的对应文件，并在 Git 中保留变更历史；若影响项目范围，再同步更新 `docs/DECISIONS.md`、`docs/PROJECT_STATUS.md` 和任务看板。

首期已冻结使用 BenchCAD 2.0 社区族 `set_screw_shaft_collar`，来源 commit 为 `035f467142888edfd0bd7cd73906f9b155c8f43c`。当前先围绕单族打通适配、Typed CAD IR、确定性构造/验证和检索闭环；第二族扩展另行决策。BenchCAD Public/Core 评测集与社区族源代码是不同资产，须遵守各自许可和数据卡边界。

## 更新约定

1. 新讨论优先更新上述计划或新增有日期的专题文件，不另建平行的“最新计划”。
2. 每项事实记录核查日期、来源链接/版本、许可状态和不确定性；不要把项目目标或社区 PR 数量表述为已发布数据集规模。
3. 计划变更注明变更原因与影响；改变项目范围时在 `docs/DECISIONS.md` 增加决策记录。
4. 原始数据、生成的 CAD 大文件或受限数据不因放入本目录而自动允许提交；先核对许可，并按仓库忽略规则管理。
