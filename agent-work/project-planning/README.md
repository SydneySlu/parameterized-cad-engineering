# 项目总体规划 Agent 工作区

这个目录保存“总体推进讨论 Agent”与项目负责人讨论后的规划材料。它是规划草稿和讨论记录区，不替代 `docs/PROJECT_STATUS.md`、`docs/PROJECT_PLAN.md`、`docs/TASKS.md` 或 `docs/DECISIONS.md` 这些正式事实源。

## 建议文件

- `discussion-log.md`：按日期追加的讨论记录。
- `architecture-options.md`：待比较的架构和推进方案。
- `open-questions.md`：尚未决策的问题、依赖和需要用户/导师确认的事项。
- `checkpoints/`：阶段性规划 checkpoint；每个 checkpoint 标明范围、已确认内容、未决事项和下一步。

规划 Agent 只写本目录，除非项目负责人或 Codex 中枢明确要求，不直接改动 `src/`、`tests/`、`data/` 或正式状态/决策文件。被确认的决策由中枢整理后写入正式文档。
